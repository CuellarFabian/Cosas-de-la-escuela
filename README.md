# Cosas de la escuela

Actividades y cuadernillos en HTML para las clases de Tecnología y Robótica.

Cada archivo es una página independiente: se abre con doble clic en cualquier navegador, sin instalar nada.

## Contenido

| Archivo | Qué es |
| --- | --- |
| `armar_computadora_game.html` | Actividad: armar una PC |
| `evaluacion_tkinter_partes_2_4.html` | Evaluación de tkinter para 6.º grado (partes 2, 3 y 4), con corrección automática. Vale como máximo el 50% de la nota total |

## Cómo usarlo

- **En la compu:** descargá el archivo `.html` y abrilo con el navegador.
- **Publicado en la web:** este repositorio está pensado para publicarse con GitHub Pages (rama `main`, carpeta raíz).
