# Cosas de la escuela

Actividades y evaluaciones en HTML para las clases de Tecnología y Robótica.
Prof. Fabián Cuellar, Escuela del Viento, Río Gallegos (Santa Cruz).

Cada archivo es una página independiente: se abre con doble clic en cualquier navegador, sin instalar nada.

**Sitio publicado:** https://cuellarfabian.github.io/Cosas-de-la-escuela/

## Contenido

| Archivo | Qué es |
| --- | --- |
| `index.html` | Página de inicio con enlaces a todas las actividades |
| `armar_computadora_game.html` | Actividad: armá tu computadora, arrastrando cada componente a su lugar |
| `evaluacion_tkinter_partes_2_4.html` | Evaluación de tkinter para 6.º grado (partes 2, 3 y 4), con corrección automática. Vale como máximo el 50% de la nota total |

## Cómo usarlo

- **En la compu:** descargá el archivo `.html` y abrilo con el navegador.
- **En la web:** el repositorio se publica con GitHub Pages (rama `main`, carpeta raíz).
